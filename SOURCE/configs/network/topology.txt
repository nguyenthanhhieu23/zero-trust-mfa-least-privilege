ACCESS FLOWS
  1. User/admin/guest -> Keycloak: OIDC login + MFA.
  2. Keycloak -> client: token containing role claim.
  3. Client -> reverse proxy: gateway validates token, role, source and path.
  4. Reverse proxy -> server: only approved service flow is allowed.
  5. Guest -> internal VLANs: denied and logged.
  6. All unspecified traffic: denied by default and logged.

ROLE POLICY
  admin: approved administrative API, MFA required, admin VLAN preferred.
  user : approved business API only, MFA required.
  guest: public/read-only service only, no internal server access.
